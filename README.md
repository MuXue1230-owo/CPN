# CPN26 Language Standard

**CPN26** is the current language standard for **CPN**.

The authoritative consolidated English normative text is [CPN26.md](CPN26.md). The same standard is organized into 32 chapters under [spec/](spec/).

The standard covers the Core language and the explicitly selected optional capabilities, including numerical execution, construction and destruction, generics, modules, concurrency, reflection, contracts, standard-library interfaces, and native C/C++ interoperability.

The normative standard is maintained in Markdown. The chapter files and consolidated edition describe the same CPN26 baseline.
